### 3. AFFILIATE E-COMMERCE
**Product Categories:**
1. Rudraksha (certified, genuine)
2. Pooja Samagri (diya, agarbatti, etc.)
3. Spiritual Books (Gita Press, etc.)
4. Meditation Accessories

**How it Works:**
- AI suggests: "Aapko Rudraksha dharan karna chahiye"
- Below response: Amazon/Flipkart link
- User clicks → buys → we get 5-15% commission

**Rules:**
- Only suggest when relevant
- Never force purchase
- Only genuine products
- Clear "affiliate link" disclosure
